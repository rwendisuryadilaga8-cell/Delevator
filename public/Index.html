Google Apps Script Web App Aktif

Portal Database Presensi Kursus

Layanan backend Google Apps Script telah terhubung ke Google Spreadsheet ini untuk menyimpan rekaman presensi kelas, data siswa, guru, dan kalkulasi invoice otomatis.

Pengaturan Database Otomatis

Klik tombol di bawah untuk memeriksa atau menginisialisasi ulang seluruh sheet (Kelas, Siswa, Guru, PresensiSiswa, PresensiGuru, RekapInvoice).
